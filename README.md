# WDTT SOCKS Relay (Stateless VPN-ретранслятор в SOCKS5)

Облегченная, быстрая и безопасная версия сервера **WDTT (WireGuard DTLS Traffic Tunnel)**. Этот скрипт разработан специально для перенаправления всего трафика подключенного WireGuard-клиента в сторонний **SOCKS5-прокси** в полностью автоматическом режиме.

В отличие от оригинальной версии, этот сервер является **полностью бесстейтовым (Stateless)** — он не требует баз данных, не создает конфигурационных файлов на диске и не имеет интеграции с Telegram. Вся логика и ключи шифрования хранятся исключительно в оперативной памяти.

---

## Ключевые особенности

1. **Ephemenal Key Generation (Эфемерные ключи)**:
   При каждом запуске сервер генерирует абсолютно новые пары ключей WireGuard для себя и для клиента прямо в RAM. При подключении авторизованный клиент динамически получает конфигурацию.
2. **Аутентификация по единственному паролю**:
   Никаких таблиц пользователей. Проверка пароля клиента осуществляется сверкой со значением, переданным в аргументе запуска (`-password`).
3. **Прозрачный TCP-прокси (Transparent Proxy)**:
   Вместо настройки системного NAT MASQUERADE, сервер поднимает локальный TCP-прокси на порту `12345` и с помощью одного правила `iptables` перенаправляет туда весь TCP-трафик клиента. Прокси извлекает оригинальный адрес назначения (`SO_ORIGINAL_DST`) и отправляет его в SOCKS5.
4. **DNS-туннелирование через SOCKS**:
   Обычные UDP DNS-запросы перехватываются встроенным DNS-сервером на интерфейсе `10.66.66.1:53` и пересылаются в публичный DNS (например, Google `8.8.8.8`) по протоколу TCP через ваш SOCKS5-прокси, исключая любые утечки DNS.
5. **Скрытность (Обфускация RTP + DTLS)**:
   Полная совместимость с оригинальным Android-клиентом. Весь трафик маскируется под RTP (голосовые вызовы) и шифруется `ChaCha20-Poly1305` с переменным размером пакетов для защиты от систем глубокого анализа пакетов (DPI).

---

## Требования к системе
* **ОС**: Linux (ядро с поддержкой iptables REDIRECT).
* **Права**: Права `root` (или привилегия `CAP_NET_ADMIN` при запуске в Docker) для управления сетевыми интерфейсами и правилами фильтрации трафика.
* **Дополнительно**: Рабочий SOCKS5 прокси-сервер.

## Быстрый старт через Docker (Рекомендуется)

Все файлы сборки подготовлены. Для запуска через Docker выполните следующие шаги:

1. Откройте файл `docker-compose.yml` и укажите параметры вашего SOCKS5-сервера и желаемый пароль для клиента:
   ```yaml
   environment:
     - CLIENT_PASSWORD=ваш_пароль_для_клиента
     - SOCKS_SERVER=1.2.3.4:1080       # IP:Порт вашего SOCKS5 прокси
     - SOCKS_USER=username             # Имя пользователя SOCKS (опционально)
     - SOCKS_PASS=password             # Пароль SOCKS (опционально)
   ```
2. Запустите Docker-контейнер:
   ```bash
   docker compose up -d --build
   ```

Контейнер автоматически скомпилирует исходный код, поднимет интерфейс WireGuard и настроит перенаправление трафика. Входящий порт сервера — `56000/UDP`.

## Классическая установка на сервер (Systemd)

Если вы хотите запустить проект без Docker:

1. **Скомпилируйте бинарный файл**:
   ```bash
   go build -o wdtt-socks server_socks.go
   ```
2. **Аргументы запуска**:
   * `-listen` — UDP-адрес и порт, на котором сервер ожидает подключения (по умолчанию `0.0.0.0:56000`).
   * `-password` — Пароль для проверки клиента.
   * `-socks-server` — Адрес вашего SOCKS5 прокси (например, `127.0.0.1:1080`).
   * `-socks-user` — Логин SOCKS5 (опционально).
   * `-socks-pass` — Пароль SOCKS5 (опционально).
   * `-wg-port` — Внутренний UDP-порт для WireGuard (по умолчанию `51820`).

3. **Пример ручного запуска**:
   ```bash
   sudo ./wdtt-socks -listen 0.0.0.0:56000 -password "mysecret" -socks-server "1.2.3.4:1080"
   ```

4. **Настройка автозапуска через Systemd**:
   Создайте файл службы `/etc/systemd/system/wdtt-socks.service`:
   ```ini
   [Unit]
   Description=WDTT Stateless SOCKS Relay Server
   After=network.target

   [Service]
   Type=simple
   User=root
   WorkingDirectory=/opt/wdtt-socks
   ExecStart=/opt/wdtt-socks/wdtt-socks -listen 0.0.0.0:56000 -password "ВАШ_ПАРОЛЬ" -socks-server "IP:ПОРТ" -socks-user "ЛОГИН" -socks-pass "ПАРОЛЬ"
   Restart=always
   RestartSec=5

   [Install]
   WantedBy=multi-user.target
   ```
   Активируйте службу:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable wdtt-socks.service
   sudo systemctl start wdtt-socks.service
   ```

## Архитектура и сетевой стек

Ниже представлена детальная схема прохождения пакетов от клиента во внешнюю сеть через SOCKS5:

```
+-----------------------------------------------------------------------------------+
|                           КОНТЕЙНЕР / ХОСТ СЕРВЕРА                                |
|                                                                                   |
|  [Клиент] --(RTP+DTLS UDP)--> [Порт 56000: DTLS Server]                           |
|                                       | (дешифрация и обфускация)                 |
|                                       v                                           |
|                           [Локальный сокет WireGuard]                             |
|                                       | (расшифровка пакета WG)                   |
|                                       v                                           |
|                           [Интерфейс ядра wdtt0]                                  |
|                                       |                                           |
|               +-----------------------+-----------------------+                   |
|               | (Маршрутизация TCP)                           | (Запросы DNS UDP) |
|               v                                               v                   |
|      [iptables REDIRECT]                            [DNS Server: 10.66.66.1:53]   |
|               |                                               |                   |
|               v                                               | (DNS-over-TCP)    |
|      [TCP Proxy: Порт 12345]                                  |                   |
|       - getOriginalDst()                                      v                   |
|               \                                              /                    |
|                \-----(подключение через SOCKS5 Dialer)------/                     |
|                                       |                                           |
|                                       v                                           |
|                          [Внешний SOCKS5 прокси]                                  |
|                                       |                                           |
|                                       v                                           |
|                                 [ИНТЕРНЕТ]                                        |
+-----------------------------------------------------------------------------------+
```
